# Barista Recipe Book

موقع إدارة وصفات للباريستا، جاهز للتشغيل باستخدام React + Vite.

## التشغيل
```bash
npm install
npm run dev
```

## البناء للإنتاج
```bash
npm run build
```

## المميزات
- بحث مباشر داخل الوصفات والمكونات والخطوات
- تصنيف كامل للأقسام
- 44 وصفة مستوردة من دليل الوصفات المرفق
- صفحة تفاصيل كاملة لكل وصفة
- وضع Barista Mode خطوة بخطوة
- مؤقت عمل
- مفضلة وآخر الوصفات
- إضافة / تعديل / حذف أي وصفة
- حفظ التعديلات محليًا في LocalStorage
- تصميم Responsive للموبايل والتابلت والكمبيوتر

ملاحظة: النسخة الحالية Frontend جاهزة للتشغيل. عند ربطها لاحقًا بـ Supabase يمكن جعل التعديلات مشتركة بين كل أجهزة الباريستا مع تسجيل دخول وصلاحيات.
