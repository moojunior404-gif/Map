# بارستا بوك — نسخة GitHub Pages (ملف واحد)

## الرفع على GitHub Pages
1. ادخل على مستودعك (`junior404-gif.github.io` أو أي مستودع تاني)
2. امسح كل الملفات القديمة
3. ارفع `index.html` ده بس (Add file → Upload files)
4. Commit
5. من Settings → Pages تأكد إن الفرع (branch) شغال على `main` والمجلد `/root`

بعد دقيقة أو اتنين، الموقع هيشتغل على نفس الرابط.

## الفرق عن نسخة Replit
- **مفيش سيرفر خالص** — كل حاجة شغالة جوه المتصفح
- **الوصفات بتتخزن في localStorage** — يعني على جهاز/متصفح المستخدم نفسه بس. لو فتحت من جهاز تاني أو مسحت بيانات المتصفح، الوصفات اللي ضفتها هتختفي (الوصفات الأساسية الـ 12 بترجع تلقائي لأنها مبرمجة جوه الكود)
- **رفع الصور:** روح لصفحة الإعدادات في الموقع وحط:
  - **Cloud name** بتاع حساب Cloudinary
  - **Upload preset** — لازم تعمل واحد Unsigned من Cloudinary Dashboard: Settings → Upload → Add upload preset → Signing Mode: Unsigned
  - بعد الحفظ، الرفع هيشتغل من نفس صفحة الإعدادات

## التعديل من الموبايل
افتح `index.html` من محرر GitHub مباشرة (زرار القلم ✏️) وعدّل أي نص أو تصميم في نفس الملف.
